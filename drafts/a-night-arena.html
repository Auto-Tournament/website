Run the tournament. Skip the spreadsheet.

Auto Tournament builds the bracket, runs the map veto, puts every match on a free server and records the result. Self-hosted and open source, with CS2 built in.

The bracket moves on by itself.

When a match ends, the winner goes through and the next match is set up. You watch; you don't copy scores.

  • Single and double elimination
  • Round robin and Swiss
  • Shuffle tournaments with balanced teams

CS2 today. More games as modules.

Games plug in as modules. CS2 ships built in. The rest are planned, starting with games that let you host servers or run lobbies through an API.

Built in

Counter-Strike 2

Your own servers with MatchZy Enhanced. Veto, live scores, demos and stats.

Planned

Team Fortress 2

Self-hosted servers, same model as CS2.

Planned

Dota 2

Lobbies created by a bot, results from the Steam Web API.

Up in five minutes.

One Docker Compose file: the web app, the API and the database. Point it at your servers and create a tournament.

Read the install guideAsk on Discord
# clone and start
git clone https://github.com/Auto-Tournament/auto-tournament.git
cd auto-tournament
cp example.env .env
docker compose -f docker/docker-compose.yml up -d
