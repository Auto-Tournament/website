Your tournament runs itself.

Build the bracket, let captains pick maps, and Auto Tournament puts every match on a free server and writes down the score. Self-hosted, open source, CS2 built in.

Set it up before the pizza arrives.

One Docker Compose file on any Linux box. The install guide takes you from here to your first tournament.

git clone https://github.com/Auto-Tournament/auto-tournament.git
cd auto-tournament
cp example.env .env
docker compose -f docker/docker-compose.yml up -d
